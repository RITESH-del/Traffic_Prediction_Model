## 6. Engineered‑feature Recommendations

| Feature | Rationale |
|---------|-----------|
| **Time‑of‑day / Day‑of‑week one‑hot** | Captures strong periodic traffic patterns. |
| **Rolling mean / std (windows 12, 24, 288)** | Mirrors observed autocorrelation at 5 min, 1 h, and 24 h lags. |
| **Spatial lag (average speed of neighboring sensors)** | Leverages adjacency; distance‑correlation analysis shows proximity matters. |
| **Lagged speeds (t‑1, t‑12, t‑288)** | Directly exploits temporal dependence. |
| **Missing‑value indicator** | Flags sensor outages for downstream imputation or masking. |
| **Peak‑hour flag** | Binary indicator for rush‑hour congestion spikes. |
| **Sensor‑pair distance** (numeric covariate when modelling interactions) | Provides context for spatial correlation strength. |
